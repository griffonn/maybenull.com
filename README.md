# maybenull.com

Source for [maybenull.com](https://maybenull.com), served by GitHub Pages from the `main` branch.

- `index.html`: the site.
- `CNAME`: tells GitHub Pages to serve this repo on maybenull.com.

DNS is at Namecheap: four A and four AAAA records on `@` point to GitHub Pages, and `www` is a CNAME to `griffonn.github.io`.
